Architecture Highlights

• Zero Disk Bottlenecks: When guests download high-resolution photos, the application returns a secure HTTP 302 redirect directly to Google Drive. The VPS bandwidth and disk space remain completely untouched.

• Instant Facial Recognition: 480px thumbnails and 512-dimensional InsightFace vector embeddings are cached locally for lightning-fast face queries.
